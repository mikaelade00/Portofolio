LaTeX Chunking & Translation

A Python pipeline that splits LaTeX documents into structured chunks, translates the prose with an LLM while leaving math, citations and commands untouched, and stitches everything back into a document that still compiles.

  • Python
  • LLM
  • LaTeX
  • JSON
View on GitHub

How it works

Documents are split by \section, \subsection and \subsubsection. Each chunk keeps its LaTeX commands, and only the text is sent to the LLM for translation.

Key contributions

  • A chunker that preserves LaTeX structure across sections, subsections and subsubsections.
  • A safe translation flow so the LLM never breaks commands or math formulas.
  • A reconstruction script that merges translated chunks into a fully compilable document.
  • JSON chunk output that plugs easily into translation models or automation pipelines.

Outcome

Translating academic papers into other languages becomes simple, with formatting and structure intact.
