Multi-Task Deep Learning for ISAC Beamforming & Localization

One model, two jobs: a CNN reads channel state information (CSI) and outputs both the optimal beam index and the user's estimated position, inspired by integrated sensing and communication (ISAC) for 6G networks.

  • Multi-task learning
  • CNN
  • ISAC / 6G
  • 64-antenna arrays

Approach

A convolutional network extracts features from CSI, and a shared network head outputs both the beam index and the user's coordinates. Training both tasks together lets each one help the other.

Features

  • Multi-task learning: one model handles beamforming prediction and coordinate localization at once.
  • Weighted loss: balances and prioritizes the two objectives during training.
  • Large arrays: designed and tested on configurations with up to 64 antennas.

Performance gain

  • +7% over single-task beamforming models.
  • 81% lower localization error than baseline approaches.

Impact

Shows how multi-task learning can improve both efficiency and accuracy in ISAC systems, supporting practical 6G deployment strategies.
