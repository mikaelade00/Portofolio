Adaptive CSI Filtering for Joint Beamforming & Localization

A deep learning framework that predicts the best beam and the user's position from high-dimensional channel state information (CSI) in mmWave massive MIMO, with a learnable filter that compresses CSI before the network sees it.

The problem

CSI in mmWave massive MIMO is huge: many antennas times many subcarriers. Feeding it straight into a network makes models slow and memory-hungry, which is a problem for real base-station deployment.

Approach

I introduced an adaptive triangular filter with attention-based weighting that compresses CSI while keeping the important spatial-frequency features. The filter is trained end-to-end with a multi-task network that predicts the beam index and the user's coordinates at the same time.

Highlights

  • Multi-task learning for joint beam prediction and coordinate localization.
  • The adaptive filter module cuts model parameters by up to 88% while preserving performance.
  • Attention-based weighting keeps the most informative CSI features during compression.
  • 88.0% top-1 beamforming accuracy and 2.30 m localization error.
  • Robust under low SNR thanks to noisy data augmentation.

Impact

A lightweight, accurate model for real-world mmWave massive MIMO deployment that uses far less compute and memory than a full-CSI baseline.
