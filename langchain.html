Moneysaurus Prototype — LangChain Finance Agent

The proof of concept behind Moneysaurus: a Telegram bot where you log expenses and income by chatting or sending a receipt photo, and an LLM agent extracts the amount, category and description and stores them for you.

  • LangChain / LangGraph
  • Gemini 2.5 Flash
  • PostgreSQL
  • Telegram Bot API
  • n8n
  • Proof of concept
View on GitHub See the live product

This is the prototype. The production version of Moneysaurus is a full platform with web and mobile apps, WhatsApp and Telegram bots, and an AI financial advisor, live at moneysaurus.id.

How it works

A LangChain-based agent interprets what the user wants, pulls structured financial data out of the message, and decides which tool to call. It handles both text and receipt images, so logging works however the user prefers to send it.

Key contributions

  • Designed the agent workflow in LangGraph to orchestrate financial reasoning and tool execution.
  • Integrated tool calling for creating, categorizing and saving transactions to the database.
  • Added short-term conversational memory to keep context across multi-turn chats.
  • Wrote prompts that reliably extract amount, category and description from messy input.
  • Combined text reasoning with receipt-image understanding for multimodal input.

Evolution: from n8n prototype to LangChain agent

The first version was built as an n8n workflow: an AI agent node with Gemini 2.5 Flash classified each message, extracted transaction details from text or images, and wrote them to a structured PostgreSQL schema. It proved the idea and the chat-first experience.

Moving to LangChain/LangGraph in code gave full control over agent state, tool definitions and memory, made the logic testable, and removed the dependency on a workflow runtime.

Tech stack

  • LangChain / LangGraph for agent orchestration and state management.
  • Gemini 2.5 Flash as the reasoning and multimodal model.
  • PostgreSQL for persistent transaction storage.
  • Telegram Bot API as the chat interface.

From prototype to production

The prototype proved that people will happily track money through chat. The production Moneysaurus builds on that with:

  • WhatsApp alongside Telegram, OCR receipt parsing and voice-to-text logging.
  • An AI financial advisor agent that calls tools over MCP.
  • Web, mobile and admin apps with wallets, budgets, goals, bill reminders and reports.
  • A production backend: FastAPI, PostgreSQL with pgvector, Celery/Redis workers and Xendit payments.
